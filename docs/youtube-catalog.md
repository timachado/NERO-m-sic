# YouTube musical search (0.9.6-dev)
Native YouTube tab queries a dedicated HTTPS endpoint authenticated with Firebase ID token. The sample Firebase Function calls YouTube Data API v3 search.list, category Music, embeddable and syndicated videos, Brazil region. Credentials remain server-side. The official visible embedded player is opened within NERO, stops when screen closes or app stops, and pauses local playback before opening. It is not the YouTube Music audio catalog; no audio extraction, offline video download, Premium session or background play.
Not deployed or configured. Requires dedicated Firebase project, enabled YouTube Data API, server API secret and deployment of server sample; Firebase Functions may require a billing plan. Do not enable billing without approval. Set GitHub repository variable NERO_YOUTUBE_ENDPOINT to the actual deployed HTTPS endpoint and rebuild. Firebase auth must be configured. The quota sample uses server-only Firestore counters; deploy rules blocking clients, configure retention and monitor quotas before deployment. Search is explicit via YouTube tab to avoid spending quota on other tabs. No video metadata is persisted in this iteration. Playlist saving for this provider still needs implementation with metadata refresh policy.
Official docs: https://developers.google.com/youtube/data/reference/rest/v3/search/list ; https://developers.google.com/youtube/iframe_api_reference ; https://developers.google.com/youtube/terms/required-minimum-functionality
