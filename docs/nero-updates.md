Não usa credenciais Brother. FCM instantâneo não implementado: esta entrega utiliza consulta periódica e aviso ao abrir. Para push instantâneo será necessária configuração FCM exclusiva NERO e validação de entrega. Nenhum release ou envio foi feito nesta revisão.
