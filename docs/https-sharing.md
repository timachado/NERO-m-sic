# HTTPS sharing — 0.9.22-dev
NERO shares HTTPS /s/<opaque id> links, not manual codes. Android verified App Links, including cold start and onNewIntent; strict host/path validation; Google sign-in before reading protected content from Firestore server. No direct source URL sent. Public landing page has no playlist data and opens the package explicitly on compatible Android browsers. Cards remain static and public, with link in caption.
Activation: use a dedicated NERO Firebase project. Configure Google auth and Firestore; obtain stable Android signing certificate and matching OAuth SHA; configure NERO_GOOGLE_SERVICES_JSON in CI; choose that project's verified Hosting hostname and set NERO_SHARE_HOST repository variable. Generate assetlinks.json using firebase/generate_assetlinks.py and actual SHA256 certificate. Deploy firebase/firestore.rules and firebase/share-hosting using firebase/firebase.json to the dedicated project only, with explicit project ID. Test assetlinks HTTPS and Android domain verification. No configured hostname means sharing fails closed; no fake public URL. No deployment performed. A saved local copy remains accessible. Links expire after 7 days. Anyone with link and Google session can access, not email-specific. Test auth rules in emulator before deployment.
