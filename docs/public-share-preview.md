# Public presentation / protected playback
0.9.24-dev separates public metadata and protected playlist data. Both documents are created atomically. Public get requires exact unguessable ID, live parent, and seven-day lifetime; list and update denied. Metadata has title, subtitle (artist only for single track), count, type and timestamp. No track identifiers, stream addresses, UID, full list or audio in public preview. Users are told before sharing. Unauthenticated and email-only sessions cannot read /nero_shared. Google session required to fetch protected playlist from server. Old links lacking public preview remain usable after sign-in. Web landing page still generic; does not expose metadata to WhatsApp crawlers. Card is static, no audio. No enforcement of Google sign-in for unrelated searches or imported local copies, only access through the shared link.
