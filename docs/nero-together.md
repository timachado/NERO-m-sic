# NERO Together 0.9.41-dev

Experimental manual two-device listening alignment on a shared private Wi-Fi network. Both devices must be paired in Connect and already playing or paused on the same portable catalog ID (YouTube or Commons), matching duration within two seconds. Host explicitly starts a five-minute foreground session. Guest requests one state snapshot over pinned mutual TLS and manually applies the bounded position/play-pause adjustment, with estimated half round-trip compensation and a 500 ms seek threshold. Reject mismatched tracks, video, local-only IDs, nonstandard playback speed, buffering, excessive latency, and unavailable player capabilities. Host mode accepts snapshot requests only; not playback commands. No audio or files sent, no automatic queue matching, no continuous correction, group sessions, internet relay or guaranteed sample-accurate synchronization. Each device plays its own source. Test two paired Android devices, pause/resume, seek, changed track, wrong peer, disconnect, and latency before promotion. Six unit tests for planner and wire validation. No production changes.
